CYBERRAKSHAK — RAW OUTPUTS
==========================

This folder is for the unedited outputs produced by running CyberRakshak for
Kuku AI Generalist Assignment — Problem 2.

Problem 2 has no supplied input pack. These are original fictional test cases
created for evaluation. Run each case through the deployed/local application.
After each multi-turn conversation, use the app's Download Chat (TXT) or
Download Chat (JSON) button and place the downloaded file in this folder.

IMPORTANT:
- Do not invent or manually write assistant responses and label them raw output.
- Do not edit, polish, or remove parts of downloaded conversations.
- Use fictional information only; never enter real banking credentials, OTPs,
  PINs, CVVs, account numbers, or personal data.
- Keep failed runs too, with a clear filename, if a test fails.
- Keep evaluation notes separate from the downloaded raw transcripts.
